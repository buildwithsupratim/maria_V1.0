# 📘 How to Use the App: Step-by-Step Guide

Welcome to **Learn with Maria** — a simple and powerful way to create personalized learning experiences for students.

---

## 🚀 Getting Started

Follow these steps to begin:

---

### 🎭 Step 1: Choose a Teaching Style (Teacher Persona)

Start by selecting a **teacher persona** that best suits the student’s needs.

**Examples:**
- 🤗 Friendly and patient  
- 📝 Exam-focused and structured  
- 📖 Story-based or visual learning  

👉 This choice determines **how the lessons will be taught**.

---

### 📋 Step 2: Review and Prepare the Curriculum

The teacher or parent goes through the curriculum they want the student to learn.

This can include:
- Topics  
- Chapters  
- Specific learning goals  

---

### 📤 Step 3: Submit the Curriculum

Upload or enter the selected curriculum into the app.

👉 This tells the system **what needs to be taught**.

---

### 🔑 Step 4: Generate Lesson Code

Once the curriculum is submitted, the app automatically generates a **unique lesson code**.

👉 This code connects the student to their lesson.

---

### 🎮 Step 5: Student Enters the Lesson Code

The student opens the app and enters the lesson code.

👉 This gives them access to their assigned lessons.

---

### 🌟 Step 6: Start Personalized Learning

The student receives **personalized, curated lessons** based on:

- ✨ The selected teacher persona  
- 📚 The submitted curriculum  

👉 Lessons are adapted to match the student’s **unique learning style and needs**.

---

## ✅ That’s It!

With just these steps, students can start learning in a way that’s **tailored specifically for them** 🎉

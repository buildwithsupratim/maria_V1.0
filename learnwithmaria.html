📘 How to Use the App:
Step-by-Step Guide

1

🎭 Choose a Teaching Style (Teacher Persona)

Start by selecting a teacher persona that best suits the student's needs. For example:

  • 🤗 Friendly and patient
  • 📝 Exam-focused and structured
  • 📖 Story-based or visual learning

This choice determines how the lessons will be taught.

2

📋 Review and Prepare the Curriculum

The teacher or parent goes through the curriculum they want the student to learn. This can include topics, chapters, or specific learning goals.

3

📤 Submit the Curriculum

Upload or enter the selected curriculum into the app. This tells the system what needs to be taught.

4

🔑 Generate Lesson Code

Once the curriculum is submitted, the app automatically generates a unique lesson code to connect the student to their lesson.

5

🎮 Student Enters the Lesson Code

The student opens the app and enters the lesson code for instant access to their assigned lessons — easy as 1, 2, 3!

6

🌟 Start Personalized Learning

The student receives personalized, curated lessons based on:

  • ✨ The selected teacher persona
  • 📚 The submitted curriculum

Lessons adapt to match the student's unique learning style and needs.

✅ That's it!

With just these steps, students can start learning in a way that's
tailored specifically for them. 🎉
